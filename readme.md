# Hanako project
## deploy.sh
| Переменная | Пример значений | Зачем |
| -------- | -------- | -------- |
| NEW_USER | inao787 | Имя нового юзера, который будет в sudo группе |
| PUBKEY | ... | Pubkey для доступа к SSH(необязательный, генерируется) |
| FRONT_END_DOMAIN | domain.ru | URL от панели |
| SUB_PUBLIC_DOMAIN | sub.domain.ru | URL он страницы с информацией об подписке |
| WILDCARD_DOMAIN | *.domain.ru | Нужен для генерации wildcard-сертификата |
| EMAIL | test@mail.gw | Нужен для генерации домена |
| TRUSTED_IP | 127.0.0.1 | Используется для настройки firewall если устанавливать панель, ограничиваем тем самым доступ другим до панели  |
| APP_PORT | 2222 | Порт с которой будет доступна нода |
